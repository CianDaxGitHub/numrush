# NumRush: Gamified Drill Card Game for Elementary Learners
## About
NumRush is an Android mobile game designed for Grade 3 students made using the [Godot Engine](https://godotengine.org/) and the [Talo](https://trytalo.com/) database.
With inspiration from Mathematical DD card games, the game provides the students with a fun and intuitive learning experience using the basic Mathematical operations.

This application was made to fulfill the 4th year Thesis requirements for the University of Rizal System.

## Gameplay Features
* Choose between different Game Modes based on the 4 Math operations, along with an extra Mixed mode to tackle all of them at once! Each mode contains 10 levels each with increasing difficulty.
  
https://github.com/user-attachments/assets/242b3c7e-2830-4266-ab97-1fc559aba870
* Solve all problems as fast as possible before time runs out! Utilize a card-like interface with a magical keyboard to solve each problem.

https://github.com/user-attachments/assets/75f0974f-688e-4550-b087-6accb95b0569
* Customize your Avatar using the Coins you acquired as you keep playing.

https://github.com/user-attachments/assets/e02a91c3-9891-4005-bdcb-4f6def821de4
* Use your Coins to purchase from the Shop that includes up to 100+ accessories for your Avatar to wear.

https://github.com/user-attachments/assets/fade5dfa-ee86-4c84-b3db-22e680a5b8a3
* Access your Game History and check all of your previous answers from each round you play; and Compete with other players through an Online Leaderboard system. (Internet access is needed to automatically share your score to the leaderboards after each round)

https://github.com/user-attachments/assets/dc5c63e4-4749-44e9-97f7-7dec456aa514
* Before playing the game, an account is required to access the game. Creating or logging into an account requires a stable internet connection. Otherwise, the game can be played both online and offline.

https://github.com/user-attachments/assets/9964c9be-d5f7-47a3-83bf-360235610f49
